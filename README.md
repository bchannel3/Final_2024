# Final 2024 – Covid91 Vaccine Study

This repository contains my final project for the Covid91 vaccine analysis.

## 📁 Files Included

- **Final_2024.Rproj**  
  The RStudio project file. Open this first to load the project correctly.

- **Final.Rmd**  
  The R Markdown file containing the full analysis and written report.

- **finalSumr2024.csv**  
  The dataset used in the analysis.

## 🧪 How to Run This Project

1. Clone or download this repository.  
2. Open **Final_2024.Rproj** in RStudio.  
3. Open **Final.Rmd**.  
4. Click **Knit** to produce the HTML output (not included in the repo).

## 📌 Requirements (Per Instructor)

- Do **not** include HTML files in the repository.
- Only `.Rmd`, `.Rproj`, and the data file should be uploaded.
- The project should knit cleanly when cloned by the instructor.
